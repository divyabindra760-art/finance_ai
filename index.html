🔎 InvestIQ

AI-Powered Investment Research Assistant

Built with ChatOllama, LangChain RAG, ChromaDB, and Gradio

🎯 What is InvestIQ?

InvestIQ is an intelligent investment research assistant that answers questions about financial documents and provides live market data. Built as a hackathon project, it demonstrates the power of combining Retrieval-Augmented Generation (RAG) with live API data and agentic AI workflows.

✨ Key Features

📄

Financial Document Search

Query 10-K reports and annual filings using advanced RAG technology. Retrieves relevant information with page citations.

📈

Live Market Data

Real-time stock prices, company fundamentals, and historical data from Alpha Vantage API.

📰

News & Sentiment

Latest financial news with AI-powered sentiment analysis to gauge market perception.

🤖

Intelligent Agent

LangGraph agent automatically selects the right tools and combines multiple data sources.

💬

Chat Interface

User-friendly Gradio UI with example questions and conversation history.

🔒

100% Local LLM

Runs on your machine using Ollama - no data sent to external LLM providers.

🛠️ Technology Stack

Python 3.13 ChatOllama (Qwen 0.6B) LangChain LangGraph ChromaDB HuggingFace Embeddings Alpha Vantage API Gradio 6.0 PyTest

🚀 Quick Start

Installation

git clone https://github.com/divyabindra760-art/finance_ai.git cd finance_ai pip install -r requirements.txt

Run the Application

python app.py

Then open your browser to http://127.0.0.1:7861

💡 Example Questions

  • 📊 "What was Apple's revenue according to the 10-K?"
  • 💰 "What is Apple's current stock price?"
  • 📈 "What are Apple's financial fundamentals?"
  • 🔍 "Analyze Apple as an investment opportunity"
